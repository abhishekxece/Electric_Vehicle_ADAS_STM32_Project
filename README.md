# 📌 About This Repository

This repository documents my **14-day Embedded Systems challenge** focused on developing an **Electric Vehicle ADAS (Advanced Driver Assistance System)** using the **STM32 Blue Pill**, **Embedded C**, **PICSimLab**, and a **Python-based Live Dashboard**.

Each day introduces a new automotive safety feature while strengthening concepts in embedded programming, sensor interfacing, UART communication, timers, GPIO, and real-time decision making.

> 💡 Every module is developed incrementally, tested in simulation, and uploaded with complete source code and project files.
